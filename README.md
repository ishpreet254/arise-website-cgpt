# ARISE Website

"Rise Beyond Imagination" — scaffold only. No sections are built out yet; this is the
folder/stack foundation everything else will sit on, per the Master Spec's build order
(Section 9).

## Stack

- **Next.js 16** (App Router), plain JavaScript — no TypeScript, to keep the learning
  curve low.
- **No Tailwind** — styling is plain CSS using custom properties (design tokens), per
  Master Spec Section 3.2.
- **GSAP** installed, not yet wired up — will drive all scroll/animation work per
  Master Spec Section 7.
- No backend yet (Supabase is Phase 2, deferred until the frontend is live).

## Design tokens (done)

`src/styles/tokens.css` holds every color, type, spacing, radius, and motion value from
Master Spec Section 2 — dark theme as `:root` (default), light theme as a
`[data-theme="light"]` override block. The color values are the spec's proposed
starting palette; swap them for exact brand hex codes if/when those exist (Master Spec
Section 8, item 3).

**Fonts:** Fraunces (display, Google Fonts) and General Sans (body, Fontshare) are
loaded via plain `<link>` tags in `src/app/layout.js` — not via `next/font`, so there's
no build-time dependency on reaching those CDNs. They load like any normal web font,
the moment a browser opens the page. **Double-check General Sans' current commercial
license on Fontshare before this goes live** (Master Spec Section 8, item 4).

**Theme toggle:** `src/components/global/ThemeToggle.js` is fully working — click it to
flip `data-theme` between `dark`/`light`, choice persists across visits via
localStorage. Its current look (a plain pill button, fixed top-right) is a temporary
stand-in — it'll be replaced by the real nav/hamburger toggle once the nav is built
(Master Spec 4.1–4.2).

## Structure

```
src/
  app/
    layout.js        — root layout, page metadata
    page.js           — composes the section stubs below, in sitemap order
    globals.css        — minimal CSS reset only (no design tokens yet)
  components/
    global/            — site-wide chrome, used on every load
      Nav.js
      Footer.js
      ThemeToggle.js    — legacy development toggle; not mounted
      CustomCursor.js   — premium desktop cursor enhancement
      CustomCursor.js
    sections/           — one file per Master Spec section 5.x, in sitemap order
      Hero.js
      Services.js
      About.js
      Portfolio.js
      Testimonials.js
      FAQ.js
      ReachOut.js
      Contact.js
  lib/                 — empty; for shared utilities (theme context, GSAP helpers) later
  styles/               — empty; design tokens (Master Spec Section 2) will land here
public/                 — empty; static assets (images/video you generate) go here
```

Every section component currently renders an empty `<section>` with no styling — they're
placeholders marking where each spec section will be built, nothing more.

## What's deliberately NOT here yet

- Any visuals, layout, or animation in the individual section components — still empty
- Global nav (real logo, links, hamburger menu) — `Nav.js` is still a stub
- Custom cursor logic — stubbed, returns `null`
- Contact/enquiry form wiring (Formspree/EmailJS)
- Any generated assets (video, images) — those are generated by you, not this tool

## Running it locally

```
npm install
npm run dev
```

Then open http://localhost:3000 — right now this will render a blank page (all
sections are empty placeholders), which is expected at this stage.
